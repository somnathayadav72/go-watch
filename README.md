# ORVYN Watch Group

An immersive, frontend-only Next.js App Router experience for a fictional six-collection watch group. Scrolling acts as the mechanism: the experience winds a crown, separates and reassembles a calibre, advances a 24-hour showroom, descends through water, starts and resets a chronograph, gains elevation, and shifts through a color prism.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run validate:assets
npm run lint
npm run build
```

## Project notes

- Next.js 16 App Router, JavaScript, CSS Modules, Motion, and Lucide React.
- All 24 watches, collection identities, imagery, textures, logos, and campaign assets are original project-local concepts.
- No commerce, account, authentication, database, API route, server action, or remote image dependency.
- Reduced-motion alternatives, touch-first catalogue behavior, keyboard navigation, focus-trapped overlays, and semantic page structure are included.

The full creative and technical brief is preserved in [PLAN.md](./PLAN.md).
